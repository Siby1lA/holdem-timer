# 홀덤 타이머

터치로 조작하는 바 홀덤용 블라인드 타이머. 설치 없이 브라우저에서 바로 쓰고, 홈 화면에 추가하면 앱처럼 열려요.

**https://siby1la.github.io/holdem-timer/**

## 기능

- 샷클락: 카드 아무 데나 터치 → 시작/30초 리셋, `시작·중지·이어서` 버튼, 10초부터 매초 알림음
- 타임칩: 진행 중인 샷클락에 +30초 (설정 가능), 핸드당 사용 횟수 표시
- 레벨 타이머: 블라인드 / 앤티 / 다음 레벨, 브레이크(칩 리무브·애드온), 레벨 종료 시 자동 진행
- 설정: 레벨별 분·SB·BB·앤티 편집, "앤티 = 빅블라인드" 토글, 샷클락·타임칩 초
- 화면 꺼짐 방지, 전체화면(안드로이드/PC), 세로·가로 반응형, 다크 모드, 테마(기본 / 홀덤)

## 홈 화면에 추가

- iPhone: Safari에서 열기 → 공유 → **홈 화면에 추가** → 아이콘으로 열면 주소창 없이 전체화면
- Android: Chrome 메뉴 → **앱 설치** 또는 **홈 화면에 추가**
